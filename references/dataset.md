# Dataset de precios de teléfonos

El conjunto de entrenamiento contiene 2,000 observaciones, 20 variables
predictoras y la variable objetivo `price_range`. Las clases 0, 1, 2 y 3
representan rangos de precio crecientes y tienen 500 observaciones cada una.

El conjunto de prueba contiene 1,000 observaciones, un identificador `id` y
las mismas 20 variables predictoras. No incluye la variable objetivo.

Los archivos originales se mantienen en `data/raw/` y se versionan con DVC.
No deben editarse manualmente.
